# 实验记录模板

复制本模板建立独立实验记录。空白模板不表示实验已运行，也不授权真实模型费用。计划变更时保留旧版本与运行记录，重新标记样本是否仍独立。

## 目标与身份

| 字段 | 填写内容 |
| --- | --- |
| 实验 ID、状态与负责人 | 日期、主题；PLANNED / RUNNING / COMPLETE / INCONCLUSIVE / STOPPED |
| 分支与基线 | 本公开仓库的分支、完整基线提交、实验提交 |
| 假设与决策 | 机制、预期改善的指标，以及结果将影响的合入或放弃决定 |
| 范围与排除项 | 文档类型、问题、质量、延迟、费用及不覆盖的场景 |

## 执行前冻结

- 记录来源、许可、获取日期、文件 SHA-256、解析版本；区分可分发样例与需用户自行获取的原文。
- 冻结问题集、金标、原页核验依据和通过标准；区分开发/回归样例与未用于调试的独立样例。未来问题、金标和人工评分不得进入抽取或回答提示。
- 写明 baseline 与实验组相同和不同的条件、运行顺序、重复次数、停止条件，以及缓存历史和模型波动等可能影响结论的因素。
- 固定代码提交、依赖、模型与权重摘要、Prompt/Schema、价格快照和预算策略。比较正式结果时优先使用干净提交。
- 分别定义正确回答、正确弃答、错误事实发布、复用、全请求费用和延迟的衡量方法。工程机制通过不等于质量或降本通过。

## 运行与费用

| 字段 | 填写内容 |
| --- | --- |
| 隔离环境 | worktree、端口、数据库、Redis 命名空间和文件卷；标明共享资源 |
| 真实调用负责人 | 统一核算跨分支和历史运行的项目总占用；独立账本不能分别重置总额 |
| 本轮上限 | 金额、请求数、输出 Token、并发、期限、价格上界及批准来源 |
| 停止与恢复 | 达上限、出现未知费用或关键错误时停止派发；保留账本和原 Run/Job，不自动重试 |

把首次查询、后台构建、抽取/Probe、失败请求与后续查询全部计入比较。原始响应、usage、未知占用和平台账单保留在获准的私有证据位置；公开仓库只提交审查后可分发的汇总与复现步骤。不同环境若不能共同约束真实调用总占用，串行执行。

## 结果与结论

记录实际提交、运行命令、时间、输入摘要和输出位置；逐题核对答案、弃答、引用、原页、正式事实状态与错误发布。报告样本量、全部模型请求、Token、估算费用和真实账单差异；将未知费用单列，不把 mock 结果当成真实模型质量或费用证据。

经验缓存实验只依据可观察的前缀身份、调用历史和供应商 usage 得出结论，不要求推断供应商精确写入时刻或每次命中覆盖的输入片段；不要把应用自定窗口描述成供应商承诺。最后说明假设是否得到支持、限制、可合入实现、不能外推的结论与重跑条件。失败或证据不足的实验也保留原标准和记录。
