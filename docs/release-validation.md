## 真实结果的解释

[质量报告](quality-results-v3.md)与[费用报告](cost-results-v3.md)对应同一清单和冻结输入。独立审查代理在真实质量请求结束后读取金标，逐项目视核对原页、正文和引用，再只读核对数据库事实与租户归属；未经外部真人财务专家评审。来源为松霖科技、玲珑轮胎的明确选页，是目的性选择的小样本。玲珑此前仅作未执行备用预筛，已在 [准备记录](../eval/release/quality/holdout-v3/README.md) 披露。金标未进入模型输入。

首次独立批次有一个明确净利润问题被错误弃答，正例仅 5/6，因此未发布。原 [失败记录](../eval/release/quality/holdout-v2/FIRST-RUN-QUALITY.md)和[费用增加 16.65% 的序列](cost-results-v1.md)完整保留；修复后的恒立重跑仅算 [回归](../eval/release/hengli-regression-after-v3.json)。最终费用减少 8.59% 只适用于本次 16 条已核对答案，不能推广为普遍降本。

## 资源与限制

本机使用 Windows Docker Desktop 的 Linux amd64 容器，Docker 获配 16 vCPU、15.26 GiB 内存；Ubuntu CI 另行从零构建运行。真实流程结束后的空闲样本：runtime 1.326 GiB、API 121.3 MiB、PostgreSQL 91.19 MiB、Redis 4.305 MiB。同资产此前冷加载与单条 Embedding 约 21.3 秒，进程峰值 RSS 约 1.82 GiB，模型下载约 2.27 GB。这些是实测观察，未测最低硬件或容量上限，构建缓存还需额外磁盘。

真实正例仅覆盖明确实体、2024 年、人民币元、合并口径的收入、成本和总净利润。毛利率有实现和回归，未包含在本轮真实正例中。扫描/OCR、复杂跨页表格、开放式问答、任意计算、多用户公网生产服务以及大规模统计质量或成本结论均不在此次验收范围。
