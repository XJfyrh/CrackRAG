## 固定质量用例

`model-inputs.json` 是唯一问题输入文件；`quality-plan.json`、`gold.json` 和本说明只供评审器使用，不进入模型、工具或文档上传。

- 六个支持正例：两发行人各收入、成本、总净利润。每项冷租户独立，收入例允许正常后台构建。
- 两个缺证据负例：只上传龙盛原页 81 或恒立原页 69，询问 2024 年合并营业收入。龙盛续页没有收入行；恒立续页底部的**母公司利润表**虽有收入，也不得替代合并收入。上方续表不能借下方母公司表的标题和单位。
- 两个不支持口径负例：龙盛调整后营业收入、恒立归母净利润。不能静默换成受支持的报告合并概念。
- 两个复用例：分别复用正常收入 seed 的原问与改写；seed 完成且事实实际发布后才运行。seed 不成功则复用 BLOCKED，不记通过。

正例弃答算失败，负例 crash/timeout 不算通过；6 / 4 / 2 分别报告，全部 12 项通过才满足本小规模质量门槛。任何根据本来源作出的语义、prompt 或 parser 修复都须将本包转回归；不可修后重跑再称独立验收。

## 短序列成本

每发行人两个新隔离租户，baseline 为 strict M3 + `build_facts=false`，build 为同策略 + `true`。每臂四问：收入、成本、重复收入、改写收入，共 16 个逻辑查询。质量租户与序列租户不互通。原文、模型、配置、价目表和同一项目账本保持一致；龙盛 baseline 先，恒立 build 先。

每步等待前台和后台结算，统计所有关联尝试、构建、重试和延迟任务。总成本包括构建投入；未知 usage 保留未知及占用，不当零。只有两臂答案均正确且费用结清才算节省比例，允许负节省。两发行人短序列只构成经验测量，不能证明普遍降本或供应商精确缓存写入时刻/TTL。总支出仍受用户的人民币 100 元总上限约束，由 root 在真实执行前绑定余额和保留额度。

## 本地下载、哈希核验和选页复现

在公共仓库根目录运行（Python 3.11+，建议 `pypdf==6.8.0`；渲染还需 Poppler）：

```powershell
python scripts/release_prepare_quality.py --manifest eval/release/quality/holdout-v2/sources.json --destination ../CrackRAG-private-validation/holdout-v2 --render --report ../CrackRAG-private-validation/holdout-v2/prepared-reproduction.json
```

`--pdftoppm` 可指定 Poppler 完整路径。首次从清单的官方 HTTPS 下载；`--verify-existing` 可离线复核。下载器只读 sources 清单，不读 gold，且没有模型请求能力。两份原 PDF 已用该脚本 fetch 函数再次下载核对哈希一致。原始文件、抽取文本和图片只保存到公共仓库外。

脚本拒绝大小/哈希/页数不匹配、源超过 20 MiB、scope 超过 32 页或覆盖不同内容。逐页核对解码 content stream、抽取文本和 mediabox，并记录选页 SHA256 和 `page_map`。准备结果格式供 driver 的 `--preparation-report` 使用。首次真实执行还须绑定最终源码/配置、计划哈希、账本余额和运行证据；此准备包没有运行结论。
