# Security policy

`main` and the latest published release are the supported lines. This project is a local demonstration system; do not expose its default deployment to an untrusted network or put provider keys in an issue.

Please use [GitHub's private vulnerability report](https://github.com/XJfyrh/CrackRAG/security/advisories/new) for a suspected security issue. Include a minimal reproduction, affected commit or release, and impact. Do not publish exploit details, credentials, private PDFs, or request traces in a public issue. For ordinary bugs and feature requests, use Issues.
